Academic Coaching Curriculum

Comprehensive computer science, application, and cutting-edge Artificial Intelligence syllabus coverage for classes IX through XII across major Indian boards.

WB Board (WBBSE / WBCHSE)

CS, Application & AI
  • Class IX - X: Computer Fundamentals, Number Systems, MS Office Suite, Basic HTML, and Introduction to C/Scratch programming.
  • Class XI - XII (Application/Science): Logic Gates & Boolean Algebra, Networking, HTML & Web Design, DBMS, and Programming in C/C++.
  • Class XI - XII (Artificial Intelligence): Newly introduced 2024-25 syllabus covering search methods, evolutionary algorithms, knowledge representation, Machine Learning, and Ethics in AI.

ICSE & ISC Board

Computer & Robotics/AI
  • ICSE (Class IX - X): Object-Oriented Programming (OOP), Java via BlueJ. Robotics & AI Curriculum: Deterministic vs Probabilistic computing, AI Project Cycle, and Robot as a System (mechanical/electronic blocks).
  • ISC (Class XI - XII): Advanced Java, Boolean Algebra, Data Structures. AI Curriculum: Natural Language Processing (NLP), Computer Vision, Artificial Neural Networks (ANN), Hypothesis Testing, and Data Preparation (NumPy/Pandas).

CBSE Board

CS, IP & AI Skill Subject
  • Class IX - X: Basics of IT, Python, HTML. AI (Skill Code 417): Introduction to Generative AI, AI Project Cycle (Problem Scoping, Data Acquisition), Neural Networks, Data Literacy, Math for AI, and basic Python.
  • Class XI - XII: Computational Thinking, Advanced Python, SQL, Networking. AI (Skill Code 843): Advanced Machine Learning models, Model Evaluation, Natural Language Processing, and advanced Python integrations.
